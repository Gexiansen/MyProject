# 家庭财务

这是一个单文件家庭财务管理工具，用来帮助家庭每月回答三个问题：

1. 我们现在处于什么位置。
2. 这个月为什么会发生这些变化。
3. 距离家庭目标和想要的生活还有多远。

应用入口位于 [`docs/index.html`](docs/index.html)，使用 React、Recharts、Tailwind CSS 和 Babel 的 CDN 版本，不需要安装依赖或执行构建。

产品信息架构、交互状态和 UX 审查记录见 [`UX_INTERACTION.md`](UX_INTERACTION.md)。

## 开始使用

### 打开页面

可以直接使用浏览器打开 `docs/index.html`，也可以在项目目录启动本地静态服务：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000/docs/
```

页面依赖 CDN 加载运行库，首次打开时需要能够访问互联网。

### 解锁页面

- 默认密码：`123456`。
- 密码固定为 6 位数字，可以通过右上角「... → 修改密码」修改。
- 刷新页面后需要重新输入密码。
- 解锁成功后会关闭密码输入焦点并回到页面顶部，避免手机键盘留下的滚动位置遮住首屏内容。
- 修改密码成功后会显示确认提示；刷新页面后请使用新密码解锁。
- 该功能只是本机页面锁，不会加密财务数据，也不是服务端账户认证。

### 首次配置

没有本地数据时，页面会载入一套演示数据，并在顶部和内容区持续标记「演示数据」。正式使用前建议按以下顺序操作：

1. 点击演示数据提示中的「清空并开始」，再选择「清空全部，从零开始」；如果只想继续体验，也可以明确选择保留演示数据。
2. 在「账户管理」中建立家庭的资产、负债、收入和支出账户。
3. 在「月度结账」中创建第一个月份并录入实际数据。
4. 根据需要在「家庭目标」中建立应急资金、教育、旅行或其他目标。
5. 完成首次数据导出，并把 JSON 备份到其他位置。

## 推荐的每月使用流程

页面顶部会显示最新财务数据月份及其状态，例如「数据截至 2026年4月 · 已结账」。这里表示全局最新数据的时间边界，不会随月度结账中选择的历史月份变化；没有月度记录时显示「尚未建立月度记录」。

如果最新记录比当前月份早至少两个月，总览和家庭目标会显示「数据已滞后」提醒。提醒只说明当前判断使用的是旧月份余额，不会改变任何计算；应先完成最新月份的月度结账，再判断当前资金压力。

如果最新月份还处于「录入中」，总览、年度小结和家庭目标会显示「录入中预览」提醒。页面会继续使用当前已录入的数字计算，但只有完成结账后才视为本月最终结果；提醒中的待处理数量包含尚未核对的初始值和仍未保存的金额草稿。

桌面端和手机端使用同一套导航：主导航为「总览」「年度小结」「家庭目标」；总览显示「本月需要更新」「继续完成月度结账」时，会提供进入月度结账的动态入口，也可以通过右上角「...」菜单进入。账户管理、导入导出、修改密码和重置数据同样收纳在「...」菜单。菜单展开后，点击菜单外任意位置即可关闭。

使用键盘时，「...」菜单打开后会自动聚焦第一项，可用方向键、Home／End 移动，按 Escape 关闭并回到「...」按钮；确认弹窗优先聚焦取消操作，账户和密码等表单弹窗优先聚焦第一个输入框，Tab 会限制在当前弹窗内循环，关闭后恢复到触发控件。手机键盘压缩页面高度时，表单弹窗可以在内部滚动。账户、目标、行动和月份等图标按钮保留原图标，但触控区域统一放大到至少 40×40px。

### 1. 选择或创建月份

从总览的月度更新入口或右上角「...」菜单进入「月度结账」后，可以选择已有月份，也可以通过月份输入框创建新月份。

页面会将两类操作分开显示：左侧「查看已有月份」用于切换历史记录，右侧「新建月份」用于按顺序建立下一条记录；新建区域会显示最新记录和建议月份，输入已存在的月份时按钮会改为「查看该月」。

展开页面底部的历史记录后，月份以明确按钮显示，可以点击，也可以通过键盘 Enter／空格键切换；当前选中月份继续使用背景色标记。

进入「账户管理」或「月度结账」后，内容区顶部会显示当前页面标题、用途说明和「返回总览」按钮，便于确认当前位置并退出操作页面。

- 选择已有月份不受结账状态限制。
- 新建月份前，目标月份之前最近一个已有月份必须已经完成结账；未结账时「新建月份」按钮会禁用，并在新建区域提示需要先完成的月份。
- 创建第一条月度记录，或补录早于当前最早记录的月份时，没有前置结账要求。

创建月份时：

- 资产和负债会沿用此前最近月份的余额，并标记为本月待核对。
- 固定支出在创建新月份时会使用账户管理中设置的默认金额；历史月份不会因为默认金额变化而被追溯改写。
- 收入和非固定支出从 `0` 开始填写，并标记为本月待处理。

### 2. 按家庭成员录入

录入顺序按「老公」「老婆」「共同」分组，每组内部依次显示：

- 现金类资产：填写可随时用于生活或应急的月末余额。
- 投资资产：填写股票、基金等会随市场波动的月末余额。
- 固定资产：填写房产等通常无法快速变现的月末余额。
- 负债：填写月末余额。
- 收入：填写当月发生额。
- 支出：填写当月发生额。

手机端通过成员切换按钮一次显示一个成员，桌面端会连续展示全部成员。成员名称旁的橙色数字表示该成员仍有多少项系统初始数值待处理，全部处理后数字自动消失。手机端每个成员区块底部还会显示「下一位」入口，并带出下一位成员的待处理数量，减少录入完成后返回顶部切换的操作。

本月尚未重新输入的资产、负债、收入和非固定支出使用浅橙色输入框：资产、负债表示仍沿用此前最近记录，收入和非固定支出表示仍使用初始值 `0`。固定支出使用账户默认金额，不进入待处理统计。点击金额输入框时会自动选中原数字，直接输入即可整体覆盖，不需要先逐位删除。只有输入有效数字后才视为已经处理；正在输入的负号、小数点不会被静默改成 `0`。空值或非法内容会在离开输入框后提示「尚未保存」，并提供「恢复原值」按钮，同时阻止结账；离开页面或刷新后，草稿和原值仍会保留。有效数值会继续自动保存，不需要手动点击保存。

首个月份的资产和负债也以 `0` 开始，并计入待核对数量；结账时需确认这些零余额确实正确。停用账户已有的历史金额仍计入合计，可以展开「停用账户的历史金额」查看。

录入区上方会汇总全家庭的现金类、投资和固定资产总额，并显示各大类较此前最近记录的变化；每个账户下方仍保留此前最近记录的余额和变化值。存在月份间隔时，页面会将比较称为「较上次记录」，避免把跨月数据误读为严格环比。

修改最新月份的固定支出时，会同步更新该账户以后月份使用的默认金额；修改历史月份只影响当月。

从账户管理修改固定金额时，会清除最新未结账月份该账户的旧金额草稿，避免旧草稿遮住新的金额。删除账户会清理相关草稿、核对状态和变化原因。

### 3. 检查本月变化

录入完成后，页面会自动展示：

- 本月收入、支出和结余。
- 净资产变化。
- 结余与非收支变化的拆解。
- 对净资产影响最大的资产或负债账户。

可以为主要变化选择「市场涨跌」「主动转入／转出」「估值调整」「偿还／新增负债」「数据修正」或其他原因。

### 4. 完成本月结账

点击「完成本月结账」后，系统会检查所有启用账户是否已经填写，并提示以下异常情况：

- 启用账户存在空值。
- 资产或负债仍沿用此前最近记录的余额，或者收入、非固定支出仍使用初始值 `0`。
- 本月收入为 `0`。
- 资产或负债余额为 `0`。
- 资产或负债较此前最近记录发生大幅变化；相邻月份显示为较上月，存在月份间隔时显示为较上次记录。

空值、非法金额和仍未完成的金额草稿属于阻断项，补齐或恢复原值后才能结账。系统会分别列出仍沿用此前记录的余额，以及仍使用初始值 `0` 的收入和非固定支出；阻断项可以直接点击「去处理」定位到对应成员和输入框，也可以通过「返回并定位」处理第一项。确认后这些项目会记录为本月已经处理。其他提示确认符合实际情况后仍可结账。

完成后该月份的金额和结账结果会被锁定，变化原因和行动复盘仍可补充，但不会改变金额。需要修正金额时可以点击「重新编辑」，确认后月份回到「录入中」；已保存的简报、行动和目标快照会保留，修正后需要再次完成结账。

### 5. 完成月度复盘

修改历史月份金额或删除月份后，后续已结账月份会标记「需要复核」，不会自动解锁。请按月份顺序重新编辑、核对并再次结账，刷新目标快照。删除账户造成历史统计变化时也会提示复核。

结账后会出现：

- 月度家庭简报：总结当前位置、变化原因和下月行动，可以复制分享。
- 上一条记录行动复盘：勾选此前最近记录中的行动是否完成，并查看关联指标的同期结果。
- 下月行动：最多记录 2 项，可以选择是否关联月结余、现金或负债指标。

关联指标只表示同期变化，不代表该行动直接导致了结果。

## 功能说明

### 总览

总览默认展示家庭最需要关注的信息：

- 「资产状态」将净资产作为主数字，并在同一卡片展示总资产、总负债，以及现金、投资和固定资产构成。
- 「本月现金流」将本月攒下作为主数字，并在同一卡片展示收入和支出。
- 家庭目标所需资金与近期平均结余的关系。
- 本月财务关注，例如负结余、净资产下滑、现金缓冲不足、负债增加或投资过度集中；设置应急资金目标后，现金缓冲会使用家庭设定的保障月数判断。
- 数据核对，例如账户缺失、大额变化未解释、最近三条记录余额不变、历史调整后待复核或长期未备份。
- 财务自由进度和预计所需时间。

点击「展开深度分析」可以查看：

- 固定支出覆盖预估。
- 资产占比和资产结构变化。
- 净资产与负债趋势。
- 收入、支出、结余和储蓄率趋势。
- 净资产增长来源。
- 行动复盘。
- 成员账户归属摘要。
- 财务自由情景推演。

所有柱状图都会直接显示一位小数的万元金额，不需要悬停才能读取。月度柱状图在手机端可以左右滑动，避免为了塞进屏幕而隐藏或挤压数值。

图表范围可以切换为「最近12条」或「全部」。「最近12条」指最近 12 条已有月度记录，不承诺覆盖连续的自然月；区间存在缺失月份时会在图表上方明确列出。

### 账户管理

账户分为四类：

| 账户类型 | 填写口径 | 补充设置 |
| --- | --- | --- |
| 资产 | 月末余额 | 现金类、投资或固定资产 |
| 负债 | 月末余额 | 无 |
| 收入 | 当月发生额 | 无 |
| 支出 | 当月发生额 | 可设为固定支出并填写默认金额 |

每个账户必须选择「老公」「老婆」或「共同」，成员名称不会写进账户标题。

账户名称为空时无法保存，页面会在名称输入框下提示并把焦点移回该字段。账户和修改密码弹窗在手机键盘占用空间时可以内部滚动，不会让顶部字段超出可操作区域。

- 现金类资产：可以随时用于生活和应急，可作为应急资金来源。
- 投资资产：价格可能波动，不计入应急资金，可作为普通家庭目标的资金来源。
- 固定资产：通常无法快速变现，不作为家庭目标资金来源。

- 停用账户：保留全部历史数据，不再出现在后续月份的月度录入中；完成下一次结账后，最新数据会按启用账户统计，可以重新启用。
- 删除账户：会同时删除该账户在所有月份中的历史数据，并改变历史统计结果。
- 已经存在月度记录的账户不能修改账户类型，避免旧金额被重新解释为另一种财务数据。
- 修改有历史记录账户的资产大类或成员归属时，页面会列出受影响月份及变更内容，确认后才会保存。

如果只是暂时不再使用某个账户，优先选择停用。

### 家庭目标

家庭目标支持：

- 普通家庭目标和应急资金两种类型；旧数据中的目标默认按普通目标处理。
- 目标名称、目标金额和目标日期。
- 优先、正常、以后三级优先级。
- 手动填写当前已准备金额。
- 关联一个或多个符合口径的资产账户，自动汇总最新余额。
- 查看完成进度、资金缺口和按期每月需准备金额。
- 查看每次结账保存的目标快照以及实际进度与计划的差异。

应急资金可以设置保障月数，系统按最近最多 12 条已有记录的平均月支出计算建议金额，并显示当前资金可覆盖的月份数。应急资金只能关联现金类资产；股票、基金和固定资产不会计入应急缓冲。普通目标可以关联现金或投资资产，固定资产不作为目标资金来源。

同一个资产账户默认只能关联一个目标，避免重复计算。总览中的「目标每月需准备」只汇总优先和正常目标，并按这些目标同时推进计算；「以后」目标不计入当前资金压力。若旧数据或导入文件中存在不符合新口径的关联账户，资金不会计入目标进度，总览会提示重新选择来源，但不会删除原始目标数据。

提交目标时，缺少名称、日期、目标金额或保障月数等问题会显示在对应字段下方，并自动聚焦第一个需要修改的字段；账户来源冲突等整体规则仍在表单底部提示。新增或编辑过程中都可以点击「取消」放弃本次修改；点击编辑目标后，表单会自动滚动到可操作位置并聚焦目标名称。

### 年度小结

首条记录缺少期初余额，只作为净资产增长的起点。首月收入、支出、结余仍完整计入收支汇总，但不计入增长来源图。只有一条记录时，可确认的净资产增长为 `0`，不代表当月没有收入或结余。

年度小结按年份汇总：

- 每个统计年度的实际覆盖月份；完整年度显示全年，不完整年度显示起止月份和已记录月数。
- 期末净资产及较此前年末变化，注明比较年份。
- 年度收入、支出、期末净资产和增长来源柱状图都会直接显示一位小数的万元数值；年度明细同时列出收入、支出和结余。
- 净资产增长中自己攒下的部分与非收支变化部分。
- 年度储蓄率。
- 期末总资产、负债、区间减债和投资集中度。

年度小结中的「较此前年末」是本统计期末净资产与此前有记录年份最后一条记录的比较，不是同期月份同比；不完整年度的收入、支出、结余和储蓄率只汇总页面标明的实际月份区间。统计区间中缺少的月份会单独列出，年度图表使用浅色虚线柱标识不完整年度，悬停时再次显示实际覆盖区间、缺少月份和已记录月数，不做年化推算。

手机端的年度明细表可以左右滑动查看，表格上方会显示滑动提示。

## 主要计算口径

```text
净资产 = 总资产 - 总负债
本月结余 = 本月收入 - 本月支出
净资产变化 = 本月净资产 - 上一条月度记录净资产（相邻月份时即为上月）
非收支变化 = 净资产变化 - 本月结余
月度储蓄率 = 本月结余 ÷ 本月收入
```

当月收入为 `0` 时，不计算该月储蓄率。

```text
应急资金建议金额 = 最近最多 12 条已有记录的平均月支出 × 保障月数
应急资金覆盖月数 = 当前已准备的现金资金 ÷ 最近最多 12 条已有记录的平均月支出
```

没有历史支出或平均月支出为 `0` 时，不计算覆盖月数，也不会自动生成大于 `0` 的建议金额。

「非收支变化」可能包含投资涨跌、房产估值、负债调整、账户增删或余额修正，不能直接理解为投资收益。

投资集中度按照「最大单一投资账户余额 ÷ 投资资产总额」计算，超过 `50%` 时只做关注提示，不代表统一投资标准。

### 财务自由计算

```text
年支出 = 最近最多 12 条已有记录的平均月支出 × 12
财务自由目标本金 = 年支出 ÷ 提取率
预计年被动收入 = 当前投资资产 × 提取率
```

“最近最多 12 条已有记录”不补齐缺失自然月；只有实际存在的月度记录参与平均。

提取率可以在 `3%` 到 `6%` 之间调整。预计所需时间按近期平均结余线性推算，不计未来投资收益和支出变化。

保守、基准、乐观情景用于观察不同收益率和支出增长率假设的影响，未计税费、投资波动和家庭计划变化，不是收益承诺。

「固定支出覆盖预估」使用最近 3 条已有记录的平均收入减去当前固定支出，只衡量固定支出覆盖能力，不包含日常开销等浮动支出。

## 数据保存与备份

### 自动保存

财务数据自动保存在当前浏览器的 `localStorage` 中。以下情况可能导致页面读取不到原数据：

- 更换浏览器或设备。
- 清除浏览器站点数据。
- 更换页面地址、端口或打开方式。
- 使用无痕模式后关闭窗口。

因此，浏览器本地数据不能替代备份。

如果本机数据损坏或无法读取，页面会暂停自动保存，不再用演示数据覆盖原内容。可先「下载原始数据」，再导入有效备份恢复；浏览器本身拒绝读取时，可能无法提供原内容下载，可先恢复浏览器存储权限后「重新读取」。

### 导出

使用右上角「... → 导出数据」。导出的文件名类似：

```text
family-finance-2026-07-16.json
```

导出完成后，页面会显示实际生成的文件名和成功提示。

JSON 包含账户、月度记录、结账状态、余额核对状态、未完成金额草稿、家庭目标类型与保障月数、行动、变化原因、目标快照、提取率和最近导出时间。页面密码不会写入导出文件。

建议至少每月结账后导出一次，并把备份保存在另一个目录或设备中。

### 导入

选择家庭财务 JSON 后，页面会先校验文件，并展示账户数、月份范围、目标数和备份时间。确认弹窗中可以先导出当前数据；只有点击「确认覆盖并导入」后，文件中的账户、记录和设置才会替换当前状态。

无效文件不会改变当前数据，页面会显示具体失败原因；导入成功后会显示导入的账户数和月度记录数。

校验覆盖账户金额、月份状态、目标、行动、目标快照与录入草稿；旧版文件缺少可选字段仍可导入。错误会尽量指出对应月份和字段。

导入不会修改当前浏览器中保存的页面密码。

### 重置

重置提供两个选项：

- 恢复为演示数据。
- 清空全部，从零开始。

这两个操作都会覆盖当前财务数据，但不会重置页面密码。执行前应先导出备份。

## 使用边界

目标历史的「本期余额变化」包含投资涨跌、估值和资金来源调整，不等于实际投入。余额进度只作计划参考；目标来源或计划改变时不再直接判断达标或落后。

- 这是家庭财务记录和复盘工具，不提供投资建议、收益保证或财务顾问服务。
- 财务自由结果和情景推演都是基于当前数据的估算，不是未来承诺。
- 成员归属摘要只反映账户分类，不代表夫妻个人贡献或实际分摊。
- 页面密码只是本机访问门槛，不是数据加密。
- 财务 JSON 包含真实家庭财务信息，请勿上传到公开仓库或发送给无关人员。
